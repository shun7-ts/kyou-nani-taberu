## 原稿

- `app-store/ja-JP/`：アプリ名、サブタイトル、プロモーション文、説明、検索キーワード。文字数・UTF-8バイト数を検証済み。最新値は `app-store/metadata-validation-20261030.json`。
- `app-store/review-notes.txt`：審査担当者向けの操作・権限・端末内保存の説明。ログイン不要。
- `app-store/submission-settings.md`：カテゴリ案、プライバシー回答案、年齢制限の判断材料、暗号化、公開時の入力控え。
- `screenshots/`：実際のアプリ画面。テスト専用の架空在庫で撮影し、通常のユーザーデータは使用していない。撮影条件は同フォルダのREADMEを参照。

初回公開では「このバージョンの最新情報」は入力対象外なので用意していない。未実装のログイン・自動週間献立生成・栄養計算などを掲載文に含めていない。

## サポート・プライバシーサイト

`site/index.html` が紹介ページ、`site/support.html` が問い合わせ・FAQ、`site/privacy.html` が公開用プライバシーポリシー。モバイル対応の静的HTMLで、外部フォント・解析・フォーム送信・外部JavaScriptは使用していない。

現在は運営者・問い合わせ先・公開URLが未確定のため、全ページに確認用原稿の表示がある。

1. `site-config.json` に公開してよい運営者名、サポートメール、HTTPSの掲載先ベースURL、著作権者名を入力する。
2. `python3 scripts/prepare-release-site.py --ready` をリポジトリのルートで実行する。未設定なら生成を止める。
3. `site/` のファイルを同じ階層のまま選んだホスティング先へ配置する。
4. 実際の公開ページの表示・問い合わせメール・相互リンクを確認し、`app-store/urls.json` の3つのURLを転記する。

原稿の編集元は `site-source/`、設定の正本は `site-config.json`。生成された `site/` を直接編集せず、原稿を直して再生成する。確認用のローカル表示は `python3 -m http.server 8765 --bind 127.0.0.1 --directory release/site` で行える。
