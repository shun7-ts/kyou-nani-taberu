# 料理画像のタグ・マイページ・見出し（2026-10-04）

## 表示

- 料理画像の左上に状態タグ。必要材料の必要量が確認できる場合だけ「作れる」、不足は「買い足し」、曖昧な数量は「量を確認」。不足と曖昧な量が両方ある場合は両方表示する。材料情報がない場合は「材料を確認」。期限切れは使える在庫に数えない。任意材料と在庫管理しない材料は従来どおり計算から除外。
- 第一候補と詳細は状態と「主食・主菜／副菜／汁物」を写真に重ねる。小さい候補写真は主状態タグを表示し、料理分類を料理名の下へ配置。大きい文字は候補写真を全幅にし、状態と分類を縦に重ねる。詳細の人数変更で状態タグも再計算する。
- 色と文字を併用し、写真上のタグに不透明に近い背景を付ける。「作れる」は食材・数量の在庫判定であり、アレルゲン等の安全判断ではない。既存の詳細の注意表示を保持。
- 「設定」は「マイページ」に変更し人物アイコンを使う。従来の人数・同意・通知・削除設定を保持。ログイン機能やログイン用のダミーボタンは追加しない。
- 冷蔵庫のページ名とタブを「マイ冷蔵庫」へ変更。トップ4ページの見出しを丸みのある太字と小さなアクセント色のアイコンで統一し、上部のコンパクトな位置へ配置。
- 冷蔵庫の種類ドロップダウンを削除。分類タグで選ぶ方式へ統一し、従来の野菜・乳卵・肉・魚・大豆・麺穀類に「すべて／きのこ／加工品／その他」を追加。調味料は既存のグループ切替から選ぶ。
- 並べ替えは右上の三本線アイコンの小さいメニューへ移動。期限順／種類順／名前順／登録順を保持。見た目を小さくしつつ標準ツールバーの操作範囲と、読み上げの名前と選択値を確保。手入力の＋も保持。
- ひとくちメモは暖色の円形背景に電球を配置。枠内余白16pt、アイコンと本文12pt、見出しと本文8pt、本文行間3pt。大きい文字はアイコンと本文を縦配置する。
