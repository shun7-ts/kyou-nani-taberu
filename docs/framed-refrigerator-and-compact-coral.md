# 冷蔵庫の固定枠とコンパクトなコーラルUI

2026-10-07。採用モックを目視し、iCloud外の `${HOME}/Developer/IOSアプリ制作` に実装。feature/data-foundation、HEAD296a78f、未コミット。

## マイ冷蔵庫

細いコーラルの大きな外枠、上下の境目、左の細い取っ手で冷蔵庫を表現。上部扉に実際の表示件数、食材／調味料／すべて、保存方法、カテゴリのコントロール。下部は標準Listを枠内へ配置し、独立してスクロールする。外枠と上部コントロールは食材の件数によって伸びない。棚や大きなイラストは追加しない。

各行に食材名、保存方法・カテゴリ、在庫、期限。タグの大きな背景を減らして文字を整理。期限なしは補助色、期限がある場合の注意／期限切れは既存の意味色を維持。食材と調味料の区分、4種類の並び替え、別名検索、追加3入口と手入力、タップ編集、スワイプ削除、Undo・復元を保持。

音声・レシート・まとめては外枠の上、タブは外枠の下。GeometryReaderが利用できる高さへ外枠を収める。文字拡大では在庫行を縦にし、追加3入口を24ptのアイコンにして読み上げ名と44pt領域を保ち、フィルターは読み上げ名と値を持つ44ptのアイコンへ。表示領域が短いときはカテゴリを表示メニューへ移し、最大文字で狭ければ追加3入口を「食材の追加」メニューにまとめる。キーボード等で230pt未満の領域になったときは上部の追加列を一時的に省いて一覧を優先し、入力終了後に戻す。手入力の＋は上部に保持。

`--ui-fridge-frame-fixture` はUI確認用のインメモリ在庫を増やすだけ。通常起動の保存データ・マスターJSONへ追加しない。

## 色とボタン

モックの明るい温かい赤コーラルを基に、輪郭と主要操作の塗りを分ける。白文字の読みやすさを保つため、塗りは輪郭より濃くする。

| 用途 | ライト | ダーク |
|---|---|---|
| 背景 | #FFFCF8 | #181311 |
| 表面 | #FFFDFB | #241B18 |
| 線画 | #FF5652 | #FF8B80 |
| 操作文字・アイコン | #CF413A | #FF8B80 |
| 主要ボタンの塗り | #D23F3A | #D23F3A |
| 押下時 | #BF342F | #BF342F |

| 選択の淡い面 | #FFECE6 | #402521 |
| 区切り | #E5DDD6 | #4D3931 |

本文ブラウン、注意・成功・エラーの意味色は保持。白文字と塗りは4.65:1、押下時5.60:1。無効時は既存の補助文字・淡い背景で区別する。食材を選ぶ等の白い枠線ボタンはコーラル文字を維持。

共通CoralPrimaryButtonStyleは縦6pt、パディング後に最小44pt。呼び出し側の44／48／52ptとスタイル側のパディングの二重計上を削除し、音声・レシートの内側縦10ptも削除。通常は約44pt、拡大文字・折り返しは必要に応じて伸びる。デザイントークンv1.3.0・HTMLの配色も同期。HTMLの冷蔵庫画面構成は今回転記していない。

## 食材ボタンの線画接続

独立した野菜・しっぽのパーツと矩形のマスクを廃止。1つのSwiftUI Shape/Path内で外枠の左上とにんじん、左下とトマトを同じ座標に接続。にんじん・トマトも共有点を持ち、右の輪郭自体を魚のしっぽへ変形。線は1.4pt、端と接合は丸く、全幅内に収める。文字用の余白は左56pt／右32pt、ラベルはネイティブで折り返す。装飾を読み上げ・タップ判定から除外し、食材の選択・解除・値は維持。

検索キーでキーボードを閉じ、検索語と結果を維持する。短い領域では上下の余白も4ptへ抑える。

## 最大文字の取り消し案内

最大文字では保存後の案内をチェックアイコン＋「取り消す」＋閉じるボタンにまとめる。保存した操作名と取り消し可能の説明はアイコンのアクセシビリティラベル／ヒントで保持し、取り消す際の確認ダイアログにも操作名を出す。長い案内をすべて縦に積むことで固定枠のListが0ptになった問題を修正。通常サイズの案内は既存の2行を保持。
