# 2026-10-07 ホームの二つの入口と料理名検索

開発場所はiCloud外 `${HOME}/Developer/IOSアプリ制作`、feature/data-foundation。旧iCloudコピーを変更しない。

## 実装

ホームに「食べたい料理から選ぶ」「食材から選ぶ」の二つの入口を配置。通常幅は横並び、375ptや最大文字では縦並び。同じコーラルの輪郭・角丸・ネイティブ文字でまとめ、44pt以上のタップ範囲を維持。料理側は縦のフォークと小さな皿を枠へ接続。食材側は葉と本体がつながった人参、トマトを維持し、右端を二本の曲線の抽象形へ整理。人参は背景色の輪郭でボタン枠から離す。既存OpenMoji原SVGとCC BY-SA 4.0出典を保持。主要ボタン #E65445、タブ #F23829を保持。上部scrollContent余白4ptも維持する。

料理の入口は全レシピ・種類すべて・食材条件なしから開く。ホームの選択食材とおすすめの種類はそのまま保持し、食材の入口では従来の選択・候補・解除を使える。

レシピ一覧の食材選択ボタンを撤去し、料理名検索窓と既存の種類メニュー（主食・主菜／副菜／汁物／すべて）を表示。検索と種類をANDで適用。ホーム下部から選択食材つきで開いた場合はその条件を維持し、条件表示・解除を残す。食材を選ぶボタンは一覧にはない。該当なしには条件リセットを用意し、語・種類・食材条件を解除。検索は既存IngredientSearchで全角・半角とひらがな・カタカナを正規化し、空白区切りの複数語をAND検索する。漢字を読みへ変換する機能ではない。レシピの内容・在庫評価・人数・詳細・献立登録・不足分の買い物追加を保持。
