# コーラル線画の食材ボタンと控えめな見出しアクセント

2026-10-07。開発先はiCloud外の `${HOME}/Developer/IOSアプリ制作`。feature/data-foundation、HEAD296a78f。未コミット。

UIUX改善チャットで採用された食材ボタンのモックと全体参考写真を目視して反映。画面の情報構成、文言、献立・買い物・在庫の計算と保存は維持。

## 反映

「食材を選ぶ」は細いコーラルのカプセル輪郭、左ににんじん・トマト、右に魚のしっぽ。SwiftUI Shape/Pathで描き、文字とシェブロンはネイティブ。選択済みの食材名、解除ボタン、既存の選択シート、別名検索を維持。ラベルは折り返し、左右の装飾用に独立した幅を確保。最小64ptのラベルで44pt以上のタップ領域。装飾・シェブロンは読み上げから除外し、ボタン名と選択値を残す。ホームと同じ食材条件を使うレシピ一覧でも共通コンポーネント。

「今日のおすすめ」の見出し右上に、短い二本のコーラル線。既存の料理分類メニューを維持し、最大文字は従来の縦配置。ホームにメモや新しい説明文は追加しない。写真の葉・きらめき等は追加していない。

本文ブラウン・表面・注意／成功／エラーの意味色は保持。主要ボタン文字のコントラストは通常4.77:1、押下4.81:1、濃いアクセント文字と背景5.21:1。共通AppTheme、デザイントークンv1.2.0、HTMLワイヤーフレームの配色を同期。HTMLの構成は維持、SwiftUIの線画ボタンそのものはHTMLへ転記していない。

文字拡大時は解除を下段右へ移し、食材名の横幅を確保する。通常文字は従来の横並び。解除の44pt枠はButtonラベル内へ配置し、UIテストで実際のボタン領域を確認。野菜線画の背面は表面色で輪郭を隠し、カプセル線がトマトの内部を横切らないようにした。
