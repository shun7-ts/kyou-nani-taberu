# 食材・料理の絞り込みと冷蔵庫の整理（2026-10-04）

ユーザーの実機レビューに従い、食材選択・料理分類・人数の初期設定・冷蔵庫と買い物の表示を変更した。

## 食材と料理を探す

- 食材選択に「すべて／冷蔵庫にある／冷蔵庫にない」と食材の種類を追加。種類は野菜・肉・魚・乳卵・調味料など既存マスターの分類を使う。読み・全半角を正規化した検索と組み合わせる。
- 条件欄は展開／折りたたみ可能。検索入力中は条件を折りたたみ結果の表示領域を確保する。大きい文字の時間・食材一致も全幅の縦並びにする。
- 「ある」は現在使える正確数量、または曖昧在庫の「ある／少ない」。期限切れ、取り除いた在庫、量0、「ない」は使用可能な在庫へ数えない。食材選択は標準マスターから1件を選ぶ方式を維持。
- ホームとレシピ一覧は「主食・主菜／副菜／汁物／すべて」で絞る。副菜6品、汁物2品、主食・主菜32品。汁物は現行カタログの2キーで分類するため、追加レシピが増えた際には分類情報を更新する。料理分類と食材指定をAND条件で適用し、該当なしの場合は別の料理へ置き換えない。
- 「お店で買う予定」と買う量入力・その量の充足フィルターを画面から削除。食材を指定して通常の在庫評価で料理を選び、献立決定で不足分を買い物へ追加する。旧モードの計算・保存の単体検証は保持し、既存の保存データを変更しない。旧モード専用UI4件は廃止した画面のテストなので取り除いた。
- 食材の解除は同じ行の小さな「× 解除」。見た目をコンパクトにしつつ操作領域44pt以上と読み上げの「食材の絞り込みを解除」を保持。
- 「選んだ食材を使う料理を表示します。」、候補の重複する理由文、1人分で評価する説明を削除。買い足し品数・量の要確認品数とその材料名は引き続きアイコン付きで表示する。
- ホーム第一候補と詳細の説明を「ひとくちメモ」の背景枠へ移す。共通料理画像は引き続き「イメージ」と明示する。

## いつもの人数

設定の「レシピ → いつもの人数」で1〜4人分を保存する。未設定・範囲外は1人分。ホーム・レシピ一覧の在庫評価と、新しく開いた詳細の人数へ反映する。詳細のStepper変更はその画面内だけで、設定の人数を書き換えない。既存の決定済み献立や買い物の数量を設定変更だけで再計算しない。端末内データ全削除で初期設定もリセットする。

## 冷蔵庫

- 登録方法を上部へ直接表示。「音声」「レシート」「まとめて」の3操作を並べ、大きい文字では縦配置。従来の登録方法メニューは削除し、右上の手入力＋を保持する。写真と音声の同意・確認・破棄・保存処理は維持する。
- 「すべて／食材／調味料」で切替。全件でも食材と調味料を別セクションに分け、調味料は既存カテゴリseasoningで判定する。グループ変更時に食材種類条件を解除し、野菜を選んだまま調味料が空になることを避ける。保存方法・検索・並び順は保持。
- 各在庫行に種類と冷蔵／冷凍／常温のカプセル型タグを表示。上部の種類チップで絞り込み、同じチップを再度押すと解除する。保存方法の既存フィルターとAND条件で使える。行のタグは分類表示であり、編集画面への操作を維持する。任意の独自タグや汁物の在庫カテゴリを新設する変更ではない。
- SwiftDataの6モデルとスキーマは変更していない。元data/・design/・scripts/、署名設定、旧iCloud制作フォルダ／不完全な.gitを保持。

## 買い物

セクションは「献立から／追加したもの」。料理名の末尾の説明を削り、確認対象は注意アイコンと「量・単位を確認」に短縮。追加・購入チェック・数量修正・購入確認・在庫登録の保存処理は保持する。登録方法3種の配置は、最後の訂正に従って冷蔵庫にだけ追加した。
