# 未使用食材を使う50品（2026-10-06）

ユーザー依頼「使われてない食材を使ったレシピを追加して」に対応。既存85品に登場しなかった143種類のうち、97種類（調味料を含む）を必須材料として使う50品を追加。合計135品（主食・主菜84、副菜38、汁物13）、詳細手順492工程。未使用は143→46件、必須材料としての料理がないものは146→48件。水を除く在庫登録対象239件で集計し、任意材料を含め一度も登場しないものを「未使用」とした。小ねぎ・かつお節の2件は任意材料だけのまま。

## 内容と作り方

野菜のおかず、魚・肉料理、麺、ご飯、朝食、汁物を追加。果物、乾燥豆、製菓材料、一部の魚等は46件残る。未使用をゼロにするための不自然な材料追加はせず、実際に作る料理の材料として組み合わせた。食材マスターの新規追加は0、総数240件を維持。

- 新しい必須食材から「食材を選ぶ」で候補を探せる。副菜・汁物にだけ使う食材は料理種類を「副菜」「汁物」または全種類に切り替える。通常ホームの主食・主菜だけには出ない。
- 1〜4人分の材料量・工程材料、工程別時間、必要量・不足量・購入・調理後の更新は既存機能につなぐ。調味料は「ある・少ない・ない」、水は在庫・買い物対象外。揚げ油は固定量目安。
- 米は生米、炊いたごはんはごはんの別マスター。乾物は乾燥時の重量を使う。水煮大豆と乾燥大豆、生魚と缶詰、加熱済みたこ／釜揚げしらすと生の製品を混同しない。原材料の種類・下処理の条件を工程本文にも書く。
- 時間は1人分を順番に作る編集上の目安。米の浸水30分・蒸らし10分は合計に含む。高野豆腐の料理の干ししいたけは前日から冷蔵で戻す約6時間を別途要し、合計33分に含まないことを概要・初工程・時間補足で明記。麺の袋、濃縮つゆの希釈、鍋・トースターの表示を優先する。
- 肉・レバーは中心まで十分加熱する。生食用まぐろ、市販の生食用たたき、加熱済みゆでだこ、食用モロヘイヤの葉等の条件を明記。人数と厚みで追加の加熱が必要。
- 写真は従来の共通イメージ。味・分量・実際の所要時間の調理検証は未実施。

## 調査と編集

参考にした料理は原文・写真を転載せず、アプリの食材マスターと1人分に合わせ分量・工程を独自編集した。調査先から再設計した料理と、一般的な組み合わせから新しく作成した料理を下表で区別する。提供元の検証済みレシピとして扱わない。
