# 必ず使いたい食材で料理を絞る

ホームの「必ず使いたい食材」で標準食材を1つ選ぶ。冷蔵庫にある利用可能な在庫を持つ食材を先に表示し、食材名・別名で検索できる。在庫にない食材も選べる。水など在庫管理対象外と、自分用食材は今回の選択対象外。

同梱レシピの固定ingredientKeyが一致し、requirementがrequired、inventoryModeがignored以外、分量が正の材料を持つ料理を表示する。任意のトッピングや名前の部分一致は対象外。「主役」を判定する分類は追加していない。条件はホームとそこから開くレシピ一覧で共有し、解除できる。再起動後の条件保存は行わない。

ホームは主食・主菜、一覧は汁物・副菜も対象。対象内では従来の一致度・要確認数・調理時間の順位を保持する。該当なしの場合、条件を緩めた別の料理へ自動で置き換えない。料理名検索は食材条件と同時に適用する。

在庫が不足・期限切れでも食材の条件は維持する。詳細の1〜4人分変更で不足を再計算し、献立決定で不足材料を既存の買い物サービスへ渡す。曖昧な在庫を勝手に正確数量へ変換せず、任意材料も買い物へ強制追加しない。料理や材料のAI生成・副菜の自動組み合わせは今回追加していない。

## 実装

`App/Domain/RecipeSuggestions.swift`で必須食材の判定と候補条件を共有する。`App/Features/RecipeViews.swift`で食材選択・検索・解除・空表示を追加。シートの表示状態はホーム／一覧が保持し、検索中は説明を畳んで結果を表示する。モデル・JSON・購入／調理保存処理は保持。
