## おすすめから追加

「今日のおすすめ」の料理カード内、情報の下に「＋ 献立に加える」。画像・名前の詳細ボタンと独立させ、追加を押してもホームを維持する。現在の「いつもの人数」で既存MealService.selectを呼び、確定不足分を買い物へ追加。量が不明な食材を勝手に買い足す扱いにはしない（詳細の明示選択で追加できる）。

有効な同じレシピがあれば「✓ 献立に追加済み」としてボタンを無効化し、処理側でも再追加を防止。解除・調理完了後は再び追加できる。短い買い物追加通知は、このカードから追加した料理の追加品があるときだけ表示する。別候補へ切り替えたときは古い通知を表示しない。人数を読み上げ用値に付け、追加済みなら実際の選択人数を読む。保存失敗は既存アラートで知らせる。
