# OpenMoji food icons

Carrot (1F955) and tomato (1F345), OpenMoji contributors.
Source: https://github.com/hfg-gmuend/openmoji/tree/005bf5bc62392a9f90e1b6429c163d17610a791e
Version: 15.1.0. Graphics licensed CC BY-SA 4.0; see LICENSE.txt.

Original black SVGs retained here. Theme.swift contains faithful SVG-to-SwiftUI
path conversions (arcs expanded to cubic curves with fontTools 4.66.1), scaled
and recolored coral. These two derived icon shapes remain CC BY-SA 4.0.
Apple SVG is retained as the source of the earlier UI iteration; it is no longer used.
Attribution is also shown in My Page > image credits.

2026-10-14: original black SVGs 1F344 (Mushroom), 1FAD8 (Beans),
1F33E (Sheaf of rice; grain category), and 1F96B (Canned food) added from
the same pinned revision. Copies in App/Resources/CategoryIcons.xcassets
are compiled as template vector images and displayed at 22pt, with their
original geometry unchanged. They remain CC BY-SA 4.0. Attribution is
included in My Page > image credits.

Carrot derivative now bridges the original gap between leaf and root into one
closed silhouette. A surface-colored clearance stroke separates it from the
button outline; the source SVG and tomato contour remain unchanged.
